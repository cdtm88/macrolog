# MacroLog — Backlog (out of scope for v1)

- Notifications and reminders of any kind. Revisit only if adherence measurably
  fails.
- Fibre, sugar, sodium, micronutrients — Whoop's Journal has no entries for them.
- Food database, barcode scanning, branded-item lookup. (The Favourites
  feature — six user-curated preset meals, see ROADMAP "Accepted post-PRD
  additions" — is an accepted carve-out that does not reopen this item:
  nothing queryable, scannable, or branded.)
- History beyond today, charts, trends, weekly summaries. Whoop is the history.
- Goals, targets, streaks, gamification.
- Exercise, weight, water, or any non-macro tracking.
- Multi-user, sync, cloud backup, App Store distribution.
- Apple Watch app.
- Offline queue with automatic retry. v1 fails loudly and lets the user retry.
